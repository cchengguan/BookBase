# BookBase
A intuitive and responsive web application showcasing a diverse array of book titles from all over the world for easy access and discovery.

## 🚀 Features
* **Dynamic Search:** Instantly look up books by title, author, keywords or ISBN.
* **Genre Filtering:** Easily narrow down books using a comprehensive category dropdown (from Self-Help and Philosophy to Sci-Fi and Romance).
* **Tracking Availability:** Redirects users interested in purchasing or borrowing to popular sites such as Amazon, Kinokuniya, Open Library, NLB and Shopee.
* **Preview:** Catch a glimpse of a book's key ideas and insights.
* **Clean Modern Visual Interface:** A beautiful, responsive grid layout complete with book cover previews and star ratings(if availiable).
* **Modern UI/UX:** Fast, lightweight, and built with a focus on seamless user interaction.


## 🛠️ Built With
* **Frontend:** React / JS
* **Styling:** CSS 
* **Build Tool:** Vite
* **API:** Google Books API, Open Library API
